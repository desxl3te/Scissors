# Frontend

Статический frontend проекта. Основные страницы:

- `index.html` — главная страница и компактный блок бронирования;
- `booking.html` — отдельная страница бронирования;
- `about.html` — страница about, подключенная к FastAPI;
- `dashboard.html` — страница дашбордов;
- `alco-test.html` — алкотестер;
- `403.html`, `404.html`, `500.html`, `503.html` — страницы ошибок.

## Запуск

```bat
run_frontend.bat
```

После этого сайт будет доступен по адресу:

`http://127.0.0.1:8080/index.html`

## Файлы

- `js/api.js` — общение с FastAPI и Flask;
- `js/site.js` — логика аккаунта, поддержки и бронирования;
- `js/about.js` — загрузка данных страницы about;
- `js/dashboard.js` — графики дашборда;
- `css/` — разнесенные CSS-файлы;
- `styles1.css` — тонкий входной файл, который подключает общий CSS из папки `css`.
