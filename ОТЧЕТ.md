Как запускать тесты
Базовый запуск
Перейти в папку backend:
cd backend
Активировать виртуальное окружение (если нужно):
.\.venv-1\Scripts\Activate.ps1
Запустить все тесты:
pytest test/ -v --no-cov
С покрытием кода
Запуск с генерацией отчёта покрытия:
pytest test/ --cov=app --cov=dashboard_service --cov-report=html --cov-report=term
Открыть HTML-отчёт в браузере:
Start-Process htmlcov/index.html
Запуск конкретного файла или теста
Только тесты авторизации:
pytest test/test_api/test_auth.py -v
Только один конкретный тест:
pytest test/test_api/test_auth.py::TestAuth::test_login_success -v
Тесты с отладочным выводом (показ print()):
pytest test/test_api/test_auth.py -v -s
Полезные флаги pytest
-v — подробный вывод (verbose)
-s — показать вывод print() в тестах
-x — остановиться после первой ошибки
--tb=short — краткий стектрейс при ошибках
--no-cov — отключить покрытие (для скорости)
--cov=app — считать покрытие для модуля app
--cov-report=html — сгенерировать HTML-отчёт
Настройка pytest.ini
Файл pytest.ini в корне backend/ содержит конфигурацию pytest:
[pytest]
Пути к папкам с тестами
testpaths = test
Имена файлов с тестами
python_files = test_*.py
Имена классов с тестами
python_classes = Test*
Имена функций с тестами
python_functions = test_*
Дополнительные опции по умолчанию
addopts =
-v # подробный вывод
--strict-markers # строгая проверка маркеров
--no-cov # отключить покрытие по умолчанию
--tb=short # краткий стектрейс
Настройки asyncio для асинхронных тестов

Как работают моки
База данных: mysql.connector.connect заменяется на MagicMock, все запросы возвращают тестовые данные
Безопасность:
passlib.context.CryptContext.verify всегда возвращает True (или настраивается в тесте)
jose.jwt.decode возвращает {"sub": "1", "email": "t@t.com"}
Файлы: app.core.files.read_json возвращает тестовый JSON
Почему моки на уровне библиотек?
При импорте from module import func Python создаёт локальную ссылку на функцию. Патч module.func не обновляет эту ссылку. Патч на уровне библиотеки (passlib, jose) перехватывает вызов гарантированно, независимо от способа импорта.
